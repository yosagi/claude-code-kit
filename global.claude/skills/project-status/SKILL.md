# あなたのタスク: プロジェクト状態のスナップショット生成

このプロジェクトの現状を、**プロジェクトの外から読んでも分かる**形に畳んで
`reports/status/current.md` に書き出す。

あなたは会話の文脈を持たない新しいコンテキストで動いている。それが狙いで、
セッション中の思い込みではなく、**ファイルに書かれている事実だけ**から要約を作る。

## 読み手を間違えないこと

このファイルの主な読み手は**このプロジェクトの外**にいる。横断で計画や提案を立てる者が、
20数プロジェクト分のスナップショットをまとめて読む。その前提から二つの制約が出る。

- **自己完結させる**。読み手は参照パスを開けない（開いても文脈がない）。
  「実装ログの続き」「例の件」のような、中を読まないと分からない書き方をしない
- **2KB を超えない**。これが横断で全部読める前提を支えている。溢れたら項目を減らす

## 読むもの

すべてプロジェクトルート基準。存在しないものはスキップする。

| 情報源 | 読む範囲 | 目的 |
|--------|----------|------|
| `reports/project_context.md` | 冒頭（目的・概要） | プロジェクト名と一行説明 |
| `work_in_progress.md` | 全文 | 進行中の作業、外部待ち |
| `tmp/work_history_draft.md` | 全文（あれば） | 今セッション分の作業。**本体にはまだ追記されていない** |
| `reports/memory/work_history.md` | 直近3エントリ | 最近の完了 |
| `reports/todos/INDEX.md` | 全文 | 件数。high のものだけ件名を拾う |
| `reports/ideas/INDEX.md` | 全文 | 件数のみ |
| `reports/inbox/INDEX.md` | 全文 | `[NEW]` の件数と送り元（本文は読まない） |
| `git status --short` | 出力 | 未コミットの件数。sandbox 由来の dotfile（`.bashrc` `.profile` `.gitconfig` `.mcp.json` `.gitmodules` 等）は数えない |

## 書くもの

`reports/status/current.md` を**毎回作り直す**（追記ではなく上書き）。
ディレクトリが無ければ作る。

```markdown
# <プロジェクト名> の状態

生成: YYYY-MM-DD HH:MM / 生成元: session-end

<プロジェクトが何であるかの一行説明>

## 進行中
- <件名> — <どこまで進んで、今どこで止まっているか>。次の一手: <一言>。参照: `パス`

## 外部待ち
- <相手プロジェクト名 or 対象>: <何を待っているか>（<送信日・開始日>）

## 控え
- TODO N 件（high: <件名>）/ IDEAS N 件
- inbox 未読 N 件（<送り元>）
- 未コミット N ファイル

## 直近の完了
- YYYY-MM-DD: <一行>
```

書き方の決まり:

- **1項目 1行**、1行は**120字程度**まで。改行して詳細を足さない。詳しくは参照パスに任せる。
  進行中の行が長くなるときは、現状と次の一手のどちらかに絞る（両方を詰め込まない）
- 進行中は**最大3件**、直近の完了は**最大2件**。多いときは新しいものを優先する
- 外部待ちは**全件**書く。横断で最も価値が出るのがここで、相手プロジェクト名を必ず入れる
- 該当が無いセクションは省略せず「なし」と書く。外の読み手には「空である」ことも情報になる
- 生成時刻は `date +"%Y-%m-%d %H:%M"` で取る。単独実行でも `生成元: session-end` でよい
- 2KB を超えたら、各行を削るのではなく**項目数を減らす**。削ったことは書かない

## やらないこと

- **外部待ちの現況確認**（他プロジェクトへの照会、ネットワークアクセス、ジョブの状態取得）。
  終了時に時間をかけても翌朝には古くなる。現況は briefing と insight の担当
- **優先順位付け**。順位はセッション開始時の状況で決まる。ここでは分類までにとどめる
- `work_in_progress.md` / TODO / IDEAS / inbox の編集。読むだけ
- inbox 本文の Read（既読化の整合が崩れる）
- 実装ログ・KB の中身の転記。参照パスで足りる

## このファイルを他が触る規約

- **生成はセッション終了時だけ**。insight は再生成しない（ファイルが存在しないときのみ種を蒔く）
- insight は末尾に `## 外部待ちの現況（YYYY-MM-DD insight 確認）` を**追記**する。
  次の生成でその節は消える。生成時刻のヘッダは insight も触らない
- 手で編集しない。正本は `work_in_progress.md` で、これはそこからの派生物
